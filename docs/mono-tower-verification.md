整段线条的像素覆盖面积检查，在 1280 × 800、DPR 1 下测得三个轴向约为 2.5028、2.4989、2.5028 像素，四种 90 度镜头方向使用相同显示宽度。DPR 2 与 DPR 3 分别约为 5.00 与 7.50 像素。390 × 844 手机比例也通过投影线宽检查。

`npm run test:browser` 在 DPR 1/2/3 下各通过 137 项原物件 GPU 检查与 126 项网站物件检查。检查覆盖球体遮挡后方线条、球体透过门内部显示、其他物件遮挡球体、门内 symbol 在球体区域隐藏、四种方向的门名平面与间距、Mono Tower 字体加载、完整单词原生排版、相同字号与 kerning、单份名称、正反阅读方向、击鼓传字仅显示图标、三种门内 symbol 的可见性与投影线宽、透明出口图案、涟漪的方块表面范围与结束状态，以及真实键盘移动、镜头旋转、跳跃、安全鼠标寻路、自动进入门、手机手势、输入释放、形态切换、浏览器选择保存、操作图示和阅读页左上站点名称。

门名使用与按键相同的 Mono Tower（Open Sans Semibold，字重 600），显示为 `Notes` 与 `Essays`。浏览器原生 Canvas 2D 以完整单词排版，字体自身的 kerning 处理相邻字母，`letterSpacing` 保持默认值 `0px`，两个名称使用相同字号、大写字母高度为 14 世界单位。文字底部与门框保持 12 世界单位间距。正面与背面 GPU 文字图像在 DPR 1/2/3 下的相对像素差异均为 0%。名称只有一个 mesh，观察背面时沿门平面水平转向。

门内 symbol 共用独立的 1.5 世界单位线条材质。四种镜头方向测得图案笔画宽度，DPR 1 为 1.4953 至 1.5014 像素，DPR 2 为 2.9976 至 3.0084 像素，DPR 3 为 4.4929 至 4.5037 像素。击鼓 symbol 使用 `chuan-zi/public/favicon.svg` 的完整 SVG 副本，由 `SVGLoader` 读取笔画中心线并参与场景绘制。

桌面 1280 × 800 与手机 390 × 844 的浏览器检查使用 `Range` 测量站点名称文字区域，列表页、notes 和 essays 的 x、y、width、height 均一致。

操作提示在最前图层显示，GPU 像素检查确认空白区域的 alpha 为 0、物件黑色内部的 alpha 为 255。桌面使用五组游戏物件动画，鼠标与 WASD 相邻，W 默认朝屏幕上方；按键使用 2 像素直角边框，Tab 仅显示文字并与其他按键保持相同高度。手机使用四组动画：单指点击、双指缩放与平移、旋转和跳跃。单指点击与涟漪同时变化，双指间距与物件缩放同步，双指移动与物件平移同步。

`tests/tutorial-harness.ts` 通过公开的 `ControlTutorial.update()` 驱动真实物理与 WebGL，桌面每种尺寸通过 785 项检查，手机每种尺寸通过 654 项检查。检查覆盖按键高亮、三种 Tab 模式、所有图像随时间变化、手指动画、透明空间与不透明表面、每帧图形在各自画布区域内、循环结束淡出和元素释放。1280 × 800、390 × 844、320 × 568、844 × 390 均分别运行桌面与触屏模式，全部通过。

真实 Chrome 多点触控检查确认单指安全地面寻路、缩放和平移后继续点击寻路、双指手势结束保持位置、操作按钮尺寸与位置保持不变、跳跃按钮与两指手势同时操作、触摸取消释放和旋转按钮操作。手机显示三个操作按钮，单指拖动与双指手势不会触发寻路。手机列表中序号、名称和箭头保持一行，站点名称显示为 `Crisply2404`。

`npm test` 的 10 项物理和导航检查覆盖连续走廊的直接路线、环绕缺口的最短安全路线及其真实物理执行、经过真实轨迹检查的跳跃连接、平台接触距离恢复与点击目标到达。类型检查及生产构建通过。Godot 参考图验证原游戏物件；网站场景使用 ADR 0004 的入口与提示规则。
