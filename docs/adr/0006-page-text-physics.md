# 网页文字物理与页面状态

日期：2026-10-13

状态：已确定

## 要求

网页形态和阅读页中的全部文字按独立字母、汉字及其他 grapheme 参与物理，包括站点名称、入口、分类、文章标题、正文和按钮文字。球体默认位于页面标题前方。每个字母可以自由平移和旋转，与球体及其他字母碰撞。滚动、尺寸变化和切换形态保留每个 URL 的状态，刷新及浏览器前进后退恢复初始排列。游戏走廊和击鼓传字使用各自操作规则。

## 决定

网页版主页入口为 Notes、Essays 与 Work。Work 在原位置使用 360 毫秒高度补间和 240 毫秒透明度补间展开项目，再次点击收回；项目依次为击鼓传字与 Hockey，地址分别为 `/chuan-zi/` 和 `/hockey/`。Work 项目由 `src/site-projects.ts` 从门配置中 `group` 为 `work` 的入口生成，游戏形态与网页形态共用项目标题和地址。收起的项目文字不参加碰撞和键盘选择，展开后继续参加逐字物理；切换形态保留展开状态，刷新恢复收起状态。

Work 的纵向引导线与球体的初始球心共用 `--entrance-axis`，从 Work 行中心延伸至最后一个项目行中心，高度与透明度随展开连续变化。引导线在球体和光标后方绘制，球体完整遮挡身后的线段；整组继续根据入口背景反色。引导线滚动至顶部栏时隐藏对应部分。所有入口保持相同字体、字号、字重、行高、行距与文字起始位置。

游戏形态右上方站点名称直接连接 GitHub 主页。网页版保留左上方主页链接，右上方形态按钮左侧提供 GitHub 图标入口。加载期间记录鼠标位置，物理与字体准备完成后创建球体和光标，并恢复该位置。自定义光标显示后隐藏系统光标；页面没有收到鼠标位置时保留系统光标。

网页光标与小球共用隔离绘制层，整体参与入口反色，双方白色轮廓交汇时保持白色。碰撞距离包含小球半径、球体线宽与光标线宽，边界接触时直接分离到相切位置。水平屏幕限制使用当前显示位置计算；到达边缘时，通过 Rapier shape cast 沿竖直方向选择最近的相切位置。移动光标按接触法线与相对速度施加冲量，恢复系数为 0.65，光标继续保持鼠标位置；球体通过 60 Hz 摩擦逐渐减速。

浏览器保留原生文字布局和链接，使用 `Intl.Segmenter` 与 `Range` 得到 grapheme 的原始位置。可见字符通过独立元素显示，原始文字继续提供布局、键盘选择和辅助阅读。移动后的链接字符继续连接原目标。

Rapier 2D 负责无重力网页平面中的碰撞。字符可以沿两个页面方向平移并自由旋转；球体使用原有显示和半径对应的碰撞范围。每次球体移动按最多 0.5 像素分配物理计算步数，接触约束的 natural frequency 为 120 Hz，使快速推动维持字符碰撞。阻尼使文字停止后保持当前位置。原生页面布局决定字体、字重、换行和自然间距。字符前景使用白色，与所在页面背景逐像素反色。

页面坐标独立于屏幕滚动位置。固定顶部栏文字按滚动更新其页面坐标，顶部显示继续保持在屏幕上。页面高度随球体和文字的移动范围增加，使移动到下方的物件可以通过滚动访问。

`sessionStorage` 保存每个 URL 的球体位移、所选入口以及字符位移与旋转。切换形态时保存并恢复，滚动继续保留物件状态；完整页面加载、同地址重新进入、浏览器前进后退和刷新清除本次标签页的保存状态。尺寸变化重新测量原生布局并保留物件位移。小球画布位于顶部栏之前，顶部栏继续遮挡正文。字符元素使用测量到的原生文字区域高度作为行高，保持原生基线与按钮字符位置。

网页 WASD 仅使用 W 朝上模式，与游戏走廊的设置分开。Tab 保留浏览器键盘导航。手机移动只从小球上开始拖动，拖动期间球体实时跟随手指路径，保留初始接触点与球心的距离，沿途文字参加连续碰撞。松手、触摸取消和多指操作在当前位置终止拖动。普通点击、文字选择和取消选择保留球体位置。链接按原目标导航，页面其他位置的拖动继续滚动。

手机游戏提示中的发言手指从右下方以 45 度角接近并接触示意小球，随后头顶对话框展开。接触对象与最左侧的地面点击提示分别呈现。桌面 WASD 键图在每段移动演示中持续高亮，颜色随演示阶段切换。

网页小球碰到尖刺时，将圆周随机分为 6–12 段长度不同的圆弧，每段独立随机散开方向、距离和旋转速度，持续 280–420 毫秒。尖刺移开后按原规则在最近标题前重生。

尚未使用过主页形态按钮的访客，会在按钮下方看到 `Switch to webpage view`，提示框的上方尖角指向按钮中心。提示采用 240 毫秒透明度与位移缩放补间；首次点击按钮后通过浏览器保存已使用状态，后续进入不再显示。
