整段线条的像素覆盖面积检查，在 1280 × 800、DPR 1 下测得三个轴向约为 2.5028、2.4989、2.5028 像素，四种 90 度镜头方向使用相同显示宽度。DPR 2 与 DPR 3 分别约为 5.00 与 7.50 像素。390 × 844 手机比例也通过投影线宽检查。

`npm run test:browser` 在 DPR 1/2/3 下各通过 137 项原物件 GPU 检查与 82 项网站物件检查。检查覆盖球体遮挡后方线条、球体透过门内部显示、其他物件遮挡球体、门内 symbol 在球体区域隐藏、四种方向的门名平面与间距、三种门内 symbol 的可见性、文字与 symbol 的投影线宽、透明出口图案、涟漪的方块表面范围与结束状态，以及真实键盘移动、镜头旋转、跳跃、安全鼠标寻路、自动进入门、双指触控、八方向按钮显示、输入释放、形态切换、浏览器选择保存和阅读页左上站点名称。

门名与 symbol 共用场景的 2.5 世界单位线条材质。四种镜头方向测得文字与图案笔画宽度，DPR 1 为 2.4870 至 2.5030 像素，DPR 2 为 4.9960 至 5.0140 像素，DPR 3 为 7.4830 至 7.5028 像素。击鼓 symbol 使用 `chuan-zi/public/favicon.svg` 的完整 SVG 副本，由 `SVGLoader` 读取笔画中心线并参与场景绘制。

`npm test` 的 9 项物理和导航检查覆盖连续走廊的直接路线、环绕缺口的最短安全路线及其真实物理执行、经过真实轨迹检查的跳跃连接。类型检查及生产构建通过。Godot 参考图验证原游戏物件；网站场景使用 ADR 0004 的入口与提示规则。
