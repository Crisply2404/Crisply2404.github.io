# 网页文字物理与页面状态

日期：2026-10-13

状态：已确定

## 要求

网页形态和阅读页中的全部文字按独立字母、汉字及其他 grapheme 参与物理，包括站点名称、入口、分类、文章标题、正文和按钮文字。球体默认位于页面标题前方。每个字母可以自由平移和旋转，与球体及其他字母碰撞。滚动、尺寸变化、切换形态和浏览器前进后退保留每个 URL 的状态，刷新恢复初始排列。游戏走廊和击鼓传字使用各自操作规则。

## 决定

浏览器保留原生文字布局和链接，使用 `Intl.Segmenter` 与 `Range` 得到 grapheme 的原始位置。可见字符通过独立元素显示，原始文字继续提供布局、键盘选择和辅助阅读。移动后的链接字符继续连接原目标。

Rapier 负责无重力网页平面中的碰撞。字符可以沿两个页面方向平移并绕垂直于页面的轴自由旋转；球体使用原有显示和半径对应的碰撞范围。阻尼使文字停止后保持当前位置。原生页面布局决定字体、字重、换行和自然间距。

页面坐标独立于屏幕滚动位置。固定顶部栏文字按滚动更新其页面坐标，顶部显示继续保持在屏幕上。页面高度随球体和文字的移动范围增加，使移动到下方的物件可以通过滚动访问。

`sessionStorage` 保存每个 URL 的球体位移、所选入口以及字符位移与旋转。页面离开或切换形态时保存，浏览器返回时恢复；刷新清除本次标签页的保存状态。尺寸变化重新测量原生布局并保留物件位移。

网页 WASD 仅使用 W 朝上模式，与游戏走廊的设置分开。Tab 保留浏览器键盘导航。手机单指点按页面空白位置移动球体；链接按原目标导航，拖动继续滚动页面。

手机游戏提示中的发言手指直接接触示意小球，随后头顶对话框展开。接触对象与最左侧的地面点击提示分别呈现。
