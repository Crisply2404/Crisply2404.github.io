## 场景与入口

走廊入口由门配置生成。门框使用 MONO TOWER 的 58 × 72 尺寸，球体半径为 20，线宽为 2.5 世界单位。门内部为不透明黑色表面，球面与门内部写入场景深度。出口图案采用透明背景。

每扇门上方显示一份面向镜头的名称，最小显示字号为 14 CSS 像素。项目名称显示为“击鼓传字”，路径为 `/chuan-zi/`。球体接近门前自动进入当前页面。走廊保持入口、平台与球体；重试回到起点。

## 点击移动

点击检测真实标准方块的顶部。安全导航图连接当前位置、目标位置与安全节点。同一高度的可行直线按行走时间计费，跳跃连接按真实物理验证得到的时间计费，A* 选择总耗时最少的可行连接。行走开始时保持当前位置，移动使用原游戏加速度与摩擦，抵达目标前减速。

有效点击产生持续 0.65 秒的白色扩散涟漪。涟漪绘制在暴露的标准方块顶部，受到球体与场景表面的深度遮挡。无法到达的点击保持当前路径。
